Primary path

Install it, then run a local Anthropic proxy.

Point an SDK-based agent at StateLens with ANTHROPIC_BASE_URL. Screenshot-bearing requests are inspected before Anthropic sees them. Safe frames become text observations. Risky frames pass through unchanged.

Install and start
npm install -g statelens

export ANTHROPIC_API_KEY=sk-ant-...
statelens proxy --provider anthropic --port 18443

export ANTHROPIC_BASE_URL=http://127.0.0.1:18443
curl http://127.0.0.1:18443/health

What happens inside

Cheap local checks first, vision only when needed.

01

02

Describe

03

Route

Forward raw pixels, send compact text, or continue from prior state.
